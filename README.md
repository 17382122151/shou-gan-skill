# 手感 (shou-gan)

**中文写作去AI味工具 — 让你的文字读起来像真人写的。**

灵感来自 [pbakaus/impeccable](https://github.com/pbakaus/impeccable)（前端UI去AI味），但专门针对**中文写作场景**做了重新设计。

---

## 这是什么？

你有没有这种感觉：AI写的中文文章，读起来"就是不对"？

- 开头永远是"在这个快节奏的时代..."
- 中间永远是"首先...其次...再次...最后..."
- 结尾永远是"让我们一起期待更加美好的未来！"

**手感（shou-gan）** 就是来干掉这些的。

它做两件事：
1. **检测**：用纯正则（不花token）扫描你的文字，标出所有AI味痕迹
2. **改写**：按照指令词，把AI腔改成真人说话的样子

## 快速开始

### 1. 安装

把 `shou-gan/` 整个文件夹复制到你的 skills 目录：

```bash
# Claude Code / Cursor / 通用 Agent Skill 格式
cp -r shou-gan ~/.claude/skills/

# 或者放到你对应的 skills 目录
```

### 2. 用检测脚本先扫一遍

```bash
python shou-gan/scripts/detect.py 你的文章.md
```

输出示例：

```
==================================================
  手感检测报告 | AI味评分: 20/100  🚨 一眼AI
==================================================

  字数: 180  |  段落: 3

🔴 P0 — 一眼假（必须改）
  [P0-01] 时代背景开场白 — 命中2次
  [P0-03] 四段式编号 — 命中4次
  [P0-04] 聊天机器人残留 — 命中1次
  ...

结论：一眼就是AI写的，需要大改。
```

### 3. 让Agent帮你改

装完 Skill 后，直接跟你的AI助手说：

> "把这段文字去套话，更口语化"
> "扫描一下这篇文章有没有AI味"
> "这篇太工整了，去完美，断节奏"

## 指令词一览

像 impeccable 的 `bolder` `polish` 一样，你可以用一个词指挥修改方向：

### 检测类
| 指令词 | 作用 |
|--------|------|
| `扫描` / `检测` | 只标出问题，不改写 |
| `诊断` | 详细报告每段哪里有问题 |
| `打分` | 给一段文字打AI味指数（0-100） |

### 修改类
| 指令词 | 作用 |
|--------|------|
| `去套话` | 删掉"在这个时代""随着发展"这类空话 |
| `拆排比` | 把三连排比拆掉一两个 |
| `加细节` | 把抽象形容词换成具体描述 |
| `更口语` | 改成聊天感：短句、用"你" |
| `更干脆` | 删废话、删修饰 |
| `去完美` | 拆掉"不仅...而且..."这种假工整 |
| `断节奏` | 打乱均匀的句子长短 |
| `删结尾` | 删掉"未来可期"式万能结尾 |
| `换词` | 替换"赋能/抓手/闭环"等黑话 |

### 风格类
| 指令词 | 作用 |
|--------|------|
| `像网文` | 短段落、多对话、留钩子 |
| `像朋友圈` | 随意、有情绪、不端着 |
| `像老师傅` | 直接、有经验判断、不堆术语 |
| `像大白话` | 全用大白话，术语要么解释要么删 |

## 检测规则

内置 **20+条无模型检测规则**，全部纯正则匹配，不花API费用，结果可复现。

分三个严重级别：

- **P0 一眼假**（必须改）：时代开场白、万能结尾、四段式、聊天残留、黑话、权威开头
- **P1 很明显**（建议改）：对仗癖、形容词堆砌、过渡词开头、伪深刻、未来叙事
- **P2 小瑕疵**（有空再改）：名词化、双重否定、破折号过多、加粗成瘾

完整规则库见 [`shou-gan/references/patterns.md`](shou-gan/references/patterns.md)。

| **shou-gan** | **中文写作** | **纯中文场景、无模型检测脚本、指令词驱动** |
