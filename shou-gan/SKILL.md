# 手感 (shou-gan) — 中文写作去AI味

让中文文字读起来像真人写的，而不是AI生成的流水账。

## 这是什么，不是什么

这是一个**写作质量工具**，不是判决书。

被标记的模式只是统计学上AI更常出现的写法，不代表一定是AI写的—— deadline赶工的人、写不熟悉领域的人、用模板套话的人，都会写出同样的形状。

这些规则是**信号**，值得拿来清理自己的文章、判断一段文字像不像AI写的；但不要拿它当学术诚信、招聘、投稿的唯一依据。

一句话：**值得改，不值得定罪。**

## 指令词 (Commands)

像 impeccable 的 `bolder` `polish` `critique` 一样，你可以用一个词指挥修改方向。

### 检测类

| 指令词 | 做什么 |
|--------|--------|
| **`扫描`** / **`检测`** | 只标出AI味在哪，不改写。用户想自己决定改哪些的时候用 |
| **`诊断`** | 详细报告：哪段、哪句、什么问题、严重程度 |
| **`打分`** | 给一段文字打个"AI味指数"（0-100） |

### 修改类

| 指令词 | 做什么 |
|--------|--------|
| **`去套话`** | 删掉所有"在这个快节奏的时代""随着XX的发展"这类空话开头和过渡 |
| **`拆排比`** | 把"三个一组"的排比句式拆掉一两个，留一个或全换成散句 |
| **`加细节`** | 把抽象的形容词换成具体的、有画面感的描述（不编造事实，只把已有信息说具体） |
| **`更口语`** | 把书面腔改成聊天感：用短句、用"你"、少用"此外/因此/然而" |
| **`更干脆`** | 删废话、删修饰、一句话能说清的不用三句 |
| **`去完美`** | 删掉"不仅...而且..."、"既...又..."这种对仗工整得假的句子 |
| **`断节奏`** | 把均匀的句子长短打乱，长句后面插短句，制造呼吸感 |
| **`删结尾`** | 删掉"让我们一起期待..."、"未来可期"这种万能结尾 |
| **`去加粗`** | 删掉不必要的加粗——真人写文章不会隔两句就加粗 |
| **`换词`** | 替换AI高频词（"赋能""抓手""闭环""链路"等） |

### 风格类

| 指令词 | 做什么 |
|--------|--------|
| **`像网文`** | 改成网文的节奏：短段落、多对话、留钩子 |
| **`像朋友圈`** | 改成朋友圈语气：随意、有情绪、不端着 |
| **`像老师傅`** | 改成干了十几年的人说话：直接、有经验判断、不堆术语 |
| **`像大白话`** | 全用大白话，专业术语要么解释要么删掉 |

**用法示例：**
- "把这段去套话，然后更口语"
- "扫描一下这篇文章有没有AI味"
- "给这段打个分，然后加细节"
- "这篇太工整了，去完美，断节奏"

## 工作模式

### 默认模式：改写

用户丢一段文字过来，默认做三件事：
1. **检测**：标出所有AI味问题
2. **改写**：直接改掉该改的
3. **报告**：简短说改了什么

### 检测模式

用户说"扫描""只检测""别改""诊断"时——
- 只列问题，不动原文
- 按严重程度分级：P0（必须改）、P1（建议改）、P2（有空再改）
- 每条引用原文句子

### 快速检测（先跑脚本）

开始任何改写之前，**先运行检测脚本**：

```bash
python scripts/detect.py <文件路径或直接传入文本>
```

脚本会输出：
- 命中了哪些规则（按类别分组）
- 每条命中的原文位置
- AI味评分（0-100）

脚本是**无模型的**——纯正则匹配，不花token，结果可复现。脚本跑完后，你再结合上下文做判断和改写。

## 检测规则概览

完整规则库见 [references/patterns.md](references/patterns.md)。

规则分六大类：

### P0 — 一眼假（必须改）
- AI开场白："在这个XX的时代""随着XX的不断发展""众所周知"
- AI结束语："让我们一起期待""未来可期""综上所述""总而言之"
- 聊天残留："希望对你有帮助""以上就是""如有疑问欢迎"
- 万能过渡："首先...其次...再次...最后"四段式
- 假大空："赋能""抓手""闭环""链路""生态"（非专业语境下）

### P1 — 很明显（建议改）
- 三连排比：连续三个结构相同的短句
- 对仗癖："不仅...而且...""既...又...""一方面...另一方面..."
- 形容词堆砌：连续两个以上形容词修饰同一个名词
- 加粗成瘾：每两三句就有一处加粗
- 段落均匀：每段都是3-4行，像Word排版出来的
- 同义词轮换：同一段里用不同词说同一个意思（"发展""进步""提升"）

### P2 — 小瑕疵（有空再改）
- 破折号过多：每千字超过3个——
- 过渡词开头："此外""另外""值得一提的是""需要注意的是"
- 万能总结句："这不仅仅是...更是..."
- 伪深刻："在这个快节奏的时代，我们需要..."
- 名词化癖：把动词变成名词（"进行了讨论"→"讨论了"）

## 改写原则

### 五条核心原则

1. **保留节奏** — 该长就长，该短就短，别把所有句子改成一样长
2. **用原文细节** — 只把原文已有的信息说具体，不编造数字、人名、经历
3. **保留作者声音** — 原文是什么语气就保持什么语气，别硬加"我觉得""说实话"
4. **保留立场** — 原文的观点和态度不能改，只是换个说法
5. **靠内容赢得强调** — 别加"非常""极其""至关重要"来强调，用具体事实

### 绝对不能加的东西

改写的时候最容易犯的错——为了"像人"反而造出了新的AI腔。以下这些**原文没有就绝对不能加**：

- **编造个人经历**："我见过太多这种情况""在我的经验里"——原文没提就不能加
- **制造紧迫感**："在这个XX的时代""现在比任何时候都..."
- **强行反转**："大家都以为X，其实Y"——原文没这个意思就不能编
- **假装坦诚**："说实话""讲真""不瞒你说"
- **加破折号演戏**：为了制造戏剧性而加——
- **碎句节奏**：把完整句子砍成碎片来假装"有节奏感"
- **编造具体细节**：原文没给的数字、人名、案例，一个都不能编

**检验标准**：每一处改动，问自己——这个信息是原文里有的吗？是用户明确要求的吗？如果都不是，就别加。
